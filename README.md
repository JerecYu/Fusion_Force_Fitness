# 諧動空間官網 — 單頁式架構

**整個網站就是 `index.html` 一個檔案。** 樣式、程式、標誌全部包在裡面，不需要打包工具（Node.js／npm）也能直接上線。

外部只載入三樣東西：Google Fonts 字型、Google Maps 地圖嵌入、LINE 官方帳號連結。網路擋掉 Google 服務時，字型會退回系統預設，其餘功能正常。

---

## 上線到 GitHub Pages

1. GitHub 右上角 **+** → **New repository**，名稱填 `fusionforce`，選 **Public**，建立
2. 進入儲存庫，點 **uploading an existing file**
3. 把 `index.html` 拖進去，按 **Commit changes**
4. **Settings** → 左側 **Pages** → Source 選 **Deploy from a branch** → Branch 選 **main** → 資料夾 **/ (root)** → **Save**

等 1–2 分鐘，網站會出現在 `https://<你的帳號>.github.io/fusionforce/`

### 綁自己的網域（選用）

1. 儲存庫根目錄新增檔案 `CNAME`，內容一行：`www.fusionforcehealth.com`
2. 網域註冊商 DNS 新增 **CNAME** 紀錄：主機名稱 `www`，指向 `<你的帳號>.github.io`
3. 回 Settings → Pages 勾選 **Enforce HTTPS**

## 網址結構

各頁面用 `#/` 路由，可以直接分享或加書籤：

| 頁面 | 網址 |
|---|---|
| 首頁 | `.../` |
| 關於諧動 | `.../#/about` |
| 服務課程 | `.../#/services` |
| 團課課表 | `.../#/schedule` |
| 價目表 | `.../#/pricing` |
| 線上預約 | `.../#/booking` |
| 團體課預約 | `.../#/gt` |
| 私人教練課預約 | `.../#/pt` |
| 私人團體班預約 | `.../#/pgt` |
| 聯絡我們 | `.../#/contact` |

瀏覽器上一頁／下一頁正常運作，輸入不存在的網址會自動回到首頁。

## 維護：改課表與價格

用文字編輯器打開 `index.html`，搜尋 **`★ 資料區`**，所有可調整的內容都在那一段。

### 改課表

```js
mon: [
  { time: '09:00', end: '10:00', name: 'TRX綜合雕塑', coach: 'Peter', lv: 'adv' },
]
```

- `lv` 只能填 `'beg'`（入門，綠）、`'int'`（中階，深藍）、`'adv'`（進階，橘）
- 新增課程加一行，取消刪一行
- 首頁、課表頁、GT 預約頁會自動同步

### 改價格

```js
gt: { single: 400, pack: 4000, packQty: 10, bonus: 2 },
```

平均價會自動算。

> 注意：價格同時也寫在部分文案裡（首頁課程卡、價目表表格）。大幅調價請一併搜尋 `NT$400`、`NT$4,000` 檢查。

### 改教練

`coaches` 陣列。`home: true` 代表會出現在首頁的教練區塊。

### 改場館資訊

搜尋 `2356-9462` 與 `信義路` 一併更新（頁尾與聯絡頁）。

## 預約功能的運作與限制

GitHub Pages 是靜態代管，**沒有資料庫**，所以做不到全館即時共用的名額。目前設計是：

使用者選好課、填完資料 → 系統產生格式化的預約訊息 → 複製傳到官方 LINE → 你確認名額後回覆

網站已明確標示「顯示的預約人數並非全館即時名額」，不會誤導客人。這也貼近你們現行「扣課紀錄在群組查」的作業方式。

日後若要真正的即時名額，可搭配以下任一種後端（都能與現有靜態網站並存，只需改 GT 預約那段程式）：

- **Google 試算表 + Apps Script** — 免費，把試算表當資料庫
- **Firebase Firestore** — 免費額度充足，即時同步
- **Supabase** — 免費額度，PostgreSQL，附 REST API

## 單頁式的取捨

**好處**：一個檔案就是整個網站，好備份、好搬移、改資料只有一個地方，頁面切換瞬間完成不用重新載入。

**代價**：SEO 上，Google 會把整站視為一個網址。所有文字內容都在 HTML 裡（不是點擊後才載入），所以搜尋引擎讀得到，但沒辦法針對「團課課表」「價目表」等關鍵字各自排名。

如果之後 SEO 變重要，可以改回多檔案版（每頁一個獨立網址），內容與設計不用改。
