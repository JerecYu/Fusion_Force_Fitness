FFF 舊系統盤點工具 搬遷前先看清楚舊資料裡裝了什麼 —— 憑印象規劃，寫出來的東西會歪

🔒 一樣完全不連網，而且輸出可以安全截圖

這一頁沒有任何一行程式碼會連上網路（按 F12 → Network 自己驗，請求數是 0）。

更重要的是：報告本身不含任何個資。手機、姓名、email、passwordHash 這些欄位只統計筆數，不顯示內容。 只有「看起來像選項」的欄位（狀態、類型、角色…）才會列出實際的值 —— 那些不是個資，而且我需要它們才寫得出搬遷邏輯。

所以下面的報告整份截圖給我都沒問題。

1一張一張貼進來

在試算表切到某一張分頁 → 選取含標題列的整個範圍 → Ctrl+C → 選好下面的分頁名稱 → 貼上 → 按「加入盤點」。
沒資料的分頁跳過就好。順序不重要，但 members 建議先貼（跨表比對要用它當基準）。

拋棄式工具，搬遷做完就可以刪掉。
